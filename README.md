# 🌐 Developer Portfolio — Personal Website

This portfolio was built to present my frontend engineering projects in a clean, responsive, and performance-optimized environment.

The focus areas included:

- Component-driven design
- SEO optimization
- Performance optimization
- Scalable layout structure
